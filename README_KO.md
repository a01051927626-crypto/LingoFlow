# LingoFlow 0.2.0 — 화면 자동번역 프로토타입

## 이번 버전에 구현한 기능
- Jetpack Compose 앱 화면
- 화면 위 표시 권한 안내
- MediaProjection 사용자 동의 화면 실행
- MediaProjection foreground service
- VirtualDisplay + ImageReader 화면 프레임 캡처
- ML Kit 일본어 OCR
- ML Kit 일본어 → 한국어 번역 모델 다운로드 및 번역
- 새롭게 인식된 문장 중복 억제(간단한 최근 문장 캐시)
- 화면 위 플로팅 번역창 표시 및 드래그 이동
- 번역 진행 알림

## 중요한 제한 및 테스트 필요 사항
이 코드는 기능을 연결한 개발용 프로토타입이며, 모든 기기/앱에서 검증된 상용 앱이 아닙니다.
- 이 실행 환경에서는 Android SDK/에뮬레이터로 빌드 및 실기기 테스트를 수행하지 못했습니다.
- OEM별 화면 캡처 동작, 메모리/배터리 사용량, 화면 회전 및 해상도 변경은 실기기 검증이 필요합니다.
- MediaProjection은 Android 버전별 동의·foreground service 정책을 따릅니다.
- 일부 앱은 FLAG_SECURE 등으로 화면 캡처를 차단합니다.
- 캡처 이미지가 주기적으로 처리되므로 민감한 정보가 보이는 화면에서는 사용하지 않는 것이 좋습니다.
- 번역 모델은 첫 실행 시 인터넷 연결이 필요할 수 있습니다.
- OCR은 말풍선 세로쓰기, 효과음, 작은 글자, 복잡한 배경에서 오인식할 수 있습니다.
- 문장 중복 제거는 간단한 문자열 기반이며, 스크롤 위치/문장 영역 기반의 정교한 중복 제거는 후속 개선이 필요합니다.
- 번역창이 화면 캡처 결과에 포함되는 기기에서는 번역문이 재인식될 수 있어 실기기 확인이 필요합니다.
- 화면 전체를 캡처하므로 알림, 비밀번호, 개인정보가 노출된 상태에서 실행하지 마세요.

## 실행 방법
1. Android Studio에서 이 폴더를 엽니다.
2. Gradle 동기화를 진행합니다. JDK 17 및 Android SDK 35가 필요합니다.
3. 실제 안드로이드 기기에 설치합니다.
4. 앱에서 화면 위 표시 권한을 허용합니다.
5. '화면 자동번역 시작'을 누릅니다.
6. Android 시스템 화면 캡처 안내에서 공유를 허용합니다.
7. 일본어가 있는 다른 앱으로 이동해 화면을 스크롤합니다.
8. 중지하려면 LingoFlow로 돌아와 '번역 중지'를 누릅니다.

## 후속 개선 권장
- Android 14+의 화면 캡처 세션 재생성/회전 대응
- OCR 영역의 좌표·문단 레이아웃 보존
- 줄 단위 번역 캐시 및 더 정교한 중복 제거
- 오버레이 투명도/글자 크기 설정 UI 연동
- 캡처 간격·해상도 최적화 및 배터리 절약 모드
- 앱 종료/프로세스 재생성 시 상태 정리
- API 35에서의 foreground service 동작 실기기 검증

## 개인정보 및 보안
화면 캡처는 사용자의 명시적 동의 후에만 시작합니다. 이 프로토타입은 캡처 화면을 외부 번역 서버로 업로드하지 않고, 기기 내 ML Kit OCR 및 번역을 사용하도록 구성했습니다. 다만 OS의 화면 공유 표시와 앱별 캡처 제한을 준수해야 합니다.
